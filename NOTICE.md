# Credits & licensing

🌐 **English** · [Español](#creditos-y-licencias)

IterationVX is **not a standalone shader pack**. It is an edit of **IterationT 3.2.0**
with a new block lighting system grafted on top. Most of the code in this repository was
written by other people, and it keeps their terms — nothing here relicenses it.

## What comes from where

| Part | Author | Notes |
|---|---|---|
| **IterationT 3.2.0** — the base pack: sky, volumetric clouds, water, TAA, bloom, GI, gbuffers, post-processing… | *Tahnass* | Itself an edit of Chocapic13' Shaders. [CurseForge](https://www.curseforge.com/minecraft/shaders/iterationt) |
| **Chocapic13' Shaders** — the ancestor of the base pack | *Chocapic13* | The lineage IterationT derives from |
| **Physics Ocean wave functions** (`shaders/Lib/IndividualFounctions/PhysicsOceans.glsl`) | *afl_ext* | Based on [this shader](https://www.shadertoy.com/view/Xdlczl), as noted in the file |
| **Voxel block lighting** (`shaders/Lib/Voxel/*`, `shadowcomp_a.csh`, and the `VOXEL_*` additions across the pack) | *me* (developed with Claude) | Inspired by [Rethinking Voxels](https://modrinth.com/shader/rethinking-voxels) by *gri573* — the concept and behaviour, **not** its code |

# Créditos y licencias

IterationVX **no es un shader pack independiente**. Es una edición de **IterationT 3.2.0**
con un sistema de iluminación de bloques nuevo injertado encima. La mayor parte del código
de este repositorio lo escribieron otras personas, y conserva sus términos — aquí no se
relicencia nada.

| Parte | Autor | Notas |
|---|---|---|
