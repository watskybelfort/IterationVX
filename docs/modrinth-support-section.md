### Before reporting

- Check **Known issues** above — it may already be fixed in the latest version.
- IterationVX needs **Iris 1.6.1+**. **OptiFine is not supported** and never will be (the pack uses compute shaders, 3D images and SSBOs).
- If something looks wrong with lighting near slabs or stairs, set `VOXEL_DETAIL` back to `1` and try again.

### What to include in a report

> `1.` Minecraft version and Iris version
> `2.` Your GPU
> `3.` Which shader settings you changed (especially anything under `VOXEL_LIGHT`)
> `4.` `logs/latest.log` if the pack fails to compile
> `5.` A screenshot or short clip — for visual bugs this is worth more than any description
